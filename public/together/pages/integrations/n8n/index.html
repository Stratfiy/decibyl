N8N + DECIBYL

Keep your workflows.
Add a conversational step.

Connect Decibyl through HTTP tools and webhooks. Let n8n keep the workflow you already built, and use an agent for the conversation or interpretation the job needs.

Discuss your n8n connection ↗
TWO CONNECTION PATTERNS

Choose where the job starts.

01

An agent calls your n8n workflow

Configure a Decibyl HTTP tool to send a validated request to an n8n webhook. Return only the fields the agent needs for the next step.

02

n8n starts or follows a Decibyl job

Use n8n’s HTTP Request capability against supported Decibyl APIs, or receive configured events. Confirm the endpoint, authentication, and payload for your deployment.

EXAMPLE: ORDER SUPPORT

A voice conversation, connected to your workflow.

ILLUSTRATIVE WORKFLOW

Check an order through n8n

  1. The agent collects the order reference.
  2. A configured HTTP tool sends it to an authenticated n8n workflow.
  3. n8n checks the connected source and returns the order status.
  4. The agent explains the result or follows the configured handoff path.
THE RESULT TO REVIEW

A bounded status response and a recorded conversation outcome.

Integration pattern, not a downloadable verified template. No native Decibyl n8n node is claimed.
SET UP THE CONNECTION

Make the interface explicit.

01

Authentication

Keep tokens and credentials server-side. Give the integration only the permissions needed for its job.

02

Input and output

Agree field names, required values, and the response the agent can safely interpret.

03

Failures and retries

Define timeouts and an idempotency strategy before enabling write actions or automatic retries.

04

Test data and handoff

Test a valid request, missing record, invalid input, and unavailable downstream service.

COST AND OWNERSHIP

Your workflow remains yours.

Your n8n hosting and connected-app charges remain with those providers. Decibyl usage is scoped separately for models, speech, calls, and execution. Check for any additional connector charges in the chosen setup.

For n8n’s own webhook behaviour and configuration, see the official n8n Webhook documentation ↗.

BEFORE YOU INTEGRATE

A few practical answers.

Is n8n built into Decibyl?＋

This page describes HTTP and webhook integration with your existing n8n environment. It does not promise an embedded n8n editor or grant a licence to redistribute n8n.

Can I use this without a voice agent?＋

Yes. A non-voice workflow can use the same connection pattern where the supported API and tools fit the job.

Does it work with every n8n workflow immediately?＋

No. Authentication, payloads, permissions, timeouts, and failure behaviour must be configured and tested.

Is a live integration running in this website?＋

No. The website explains the connection pattern. A connected demonstration needs an agreed test workflow and authorised access.
