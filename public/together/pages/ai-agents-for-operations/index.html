QUESTIONS BEFORE THE FIRST RUN

Know what you are putting to work.

How are operations agents different from a scheduled reminder?＋

A fixed reminder follows predefined rules. An AI agent can also interpret text, extract information, and use tools where the job needs it. Use deterministic rules for predictable steps and AI for interpretation.

Can we keep our n8n workflows?＋

Yes, Decibyl can connect through configured HTTP tools and webhooks. Keep an existing workflow and use an agent where conversation or interpretation adds value.

Can agents learn from all employee activity?＋

Do not assume unrestricted observation. Context must come from supported, authorised sources. The broader shared workspace and cross-agent activity experience is in development.

What is a good operations KPI?＋

Compare manual touches, turnaround time, completed updates, correction effort, and cost with the current process. Track task quality alongside speed.
