# Site audit — 12 September 2026

Audited at `e9b238a`. Run with the [gstack](https://github.com/garrytan/gstack) skill suite
as part of a full product audit covering this repository and `Stratfiy/echowave-redesign`.
The platform half lives at `echowave/docs/audits/2026-09-12-gstack-full-product-audit.md`;
this file is the marketing site's own findings, so they can be worked without reading that.

**Verdict.** The engineering is in good shape. The exposure is in claims and compliance.

## Findings

### 1. `'20+ businesses'` is a fabricated customer count — CRITICAL

`components/marketing/LivingProofWorld.tsx:6`, `:95`

```tsx
const customerSignals = [
  '20+ businesses',
```
```tsx
<div className="living-ribbon-shell" aria-label="Trusted by more than twenty businesses across India">
```

`data/proof.ts` opens with *"⚠️ ZERO INVENTED CUSTOMERS. This is a legal and reputational
constraint, not a style preference."* `logos` and `caseStudies` are both empty arrays. The
three named engagements are anonymised, two are "Pilot in progress" and the third is
"80,000 calls scoped" — a scoped number, not a delivered customer. The claim is also the
element's accessible name, so it is what a screen reader announces. Under the Consumer
Protection Act 2019 a false customer-volume claim is a misleading advertisement.

**Fix:** delete the string and rewrite the `aria-label` to describe what is shown.
`proofSub` already has the right line: *"No invented logos and no invented counts."*

### 2. "40+ languages" is four times the data file, and it is in the JSON-LD on every page — HIGH

`lib/site.ts:87`, `components/marketing/HomeHero.tsx:53`, `:65`

`data/languages.ts` lists ten. `data/features.ts:115` says "10+ languages",
`data/competitors.ts:39` says "10+ live", `components/story/CinematicIntro.tsx:80` says
"10+ languages" — so the home page contradicts the rest of the site and itself. Because
`site.description` feeds `organizationSchema()`, `webSiteSchema()` and
`softwareApplicationSchema()`, "40+" is asserted in structured data on all 65 pages and
repeated in `llms.txt`, which is exactly where answer engines will quote it.

**Fix:** one number, derived from `languages.length`. If "40+" means "whatever the
underlying stack supports", say that, the way `data/competitors.ts:39` already does.

Same class: `24/7` and `<60s lead follow-up` are presented as product facts on the home
page while `app/legal/terms/page.tsx:81` says *"we do not currently offer a contractual
uptime SLA. We would rather say that plainly than publish a number we cannot stand behind."*

### 3. No DPDP notice or consent at the point of collection — CRITICAL

`components/forms/LeadForm.tsx`, `/book-a-demo`, `/waitlist`, `/contact`

Grepping all four for `privacy`, `consent` or `DPDP` returns nothing. The demo form collects
name, work email, phone, company, vertical, call volume and free text, plus a server-side IP
hash and user agent, and the only text near the submit button is a promise to call back.
DPDP §5 requires an itemised notice at or before collection. A footer link is not that
notice.

**Fix:** a consent line above the submit button naming the purpose and linking
`/legal/privacy`.

### 4. The privacy policy's sub-processor list omits three processors the code uses — HIGH

`app/legal/privacy/page.tsx:77-85`, worded as exhaustive ("Only the service providers we
need"). Missing:

- **Resend** — `lib/email.ts:36` sends the lead's address on every waitlist signup.
- **The n8n webhook destination** — `app/api/leads/route.ts:87` posts the complete record,
  including name, phone, company and message, to `N8N_LEAD_WEBHOOK_URL`.
- **Notion** — the README's own flow, and `supabase/schema.sql:28` has the `notion_id`
  column for it.

### 5. The IP salt falls back to a public literal — HIGH

`lib/rate-limit.ts:17-20`

```ts
const salt = process.env.N8N_WEBHOOK_SECRET ?? 'decibyl';
```

`N8N_WEBHOOK_SECRET` is documented as optional. Unset, every `ip_hash` is
`sha256("decibyl:" + ip)` against a salt published in this repo — 2^32 hashes, so it is a
reversible identifier. `app/legal/privacy/page.tsx:38` says *"a salted one-way hash... We do
not store your raw IP address."*

**Fix:** a dedicated `IP_HASH_SALT`, skip storing `ip_hash` when it is absent, and stop
reusing one secret as both a salt and an HMAC key.

### 6. `/api/leads` is an unauthenticated email trigger behind a limiter that does not limit — HIGH

`app/api/leads/route.ts:92`, `lib/rate-limit.ts:12-15`

`POST {"form_type":"waitlist","email":"victim@example.com"}` sends mail from the
Resend-verified domain to an attacker-chosen address. Content is fixed, so there is no
injection; the cost is reputation and quota. The brake is a module-scope `Map`, and
`export const dynamic = 'force-dynamic'` means every request is a fresh Vercel invocation,
so a concurrent burst faces no ceiling. The file's own comment acknowledges this and
proposes the fix.

Also: `{ ok: true, duplicate: true }` is an email-enumeration oracle the client never reads.

### 7. 7.2 MB of unoptimised PNG, four of them bypassing the image optimiser — HIGH

```
1,914,789  public/media/story/decibyl-room-04-commerce-support.png
1,873,850  public/media/home/living-operations-world.png
1,850,618  public/media/story/decibyl-room-03-property-leads.png
1,705,655  public/media/story/decibyl-room-05-call-receipt.png
1,688,897  public/media/scene-one/decibyl-office-command-center.png
```

`components/story/CinematicIntro.tsx:57` and `components/story/ScrollStory.tsx:180` render
theirs through raw `<img>` with an eslint-disable, so `next.config.ts`'s
`formats: ['image/avif','image/webp']` never applies: no WebP, no `srcset`, no `sizes`, no
`width`/`height` (so each is a CLS event). `decibyl-office-command-center.png` also carries
`fetchPriority="high"` and is the LCP element of `/experience` — the page the hero CTA sends
people to. Two sibling chapters already have 38 KB WebP derivatives, so the pipeline is
understood and was not applied to the rest.

`components/marketing/LivingProofWorld.tsx:75` compounds it: `priority` on an image sitting
after ~470svh of scroll story, with `sizes="(max-width: 768px) 150vw"` asking phones for an
image 1.5× their viewport.

1.53 MB of media referenced by nothing is still deployed
(`decibyl-office-welcome.mp4`, `-hd.webp`, `-poster.webp`), while `OPEN-ITEMS.md` says
*"2.1 MB of unused media is no longer deployed."*

Nine font families preload on all 65 pages, including six Indic faces on `/legal/refund`,
which renders none of them. Set `preload: false` on those six.

### 8. Secondary body text fails AA contrast site-wide — HIGH

`app/globals.css:24,26`. `--color-iron` and `--color-slate` are both `#6b7589`, which is
**4.23:1** on `--color-fog` `#f1f5f9`. `Section surface="white"` renders `bg-fog` and
`SectionHead`'s sub is `text-slate`, so every sub-heading in a white section fails —
roughly 37 occurrences across `/pricing`, `/security`, `/compare`, `/developers`,
`/partners`, `/voice-ai`, `/how-it-works`, `/use-cases`, `/solutions` and every city and
language page. A regression: `OPEN-ITEMS.md` records `#676C77` at 4.8:1 and claims 96-97
Lighthouse accessibility. The violet redesign moved the token and the note was not updated.

**Fix:** darken to about `#5C6373` (5.1:1 on fog).

Cheap a11y fixes alongside it: the hero rotator is a permanent unpausable `aria-live`
region announcing a new word every 2.6 s (WCAG 2.2.2) and is decorative, so it should just
lose the attribute; field errors set `aria-invalid` with no `aria-describedby` and no
`role="alert"`; the success state unmounts the form so focus falls to `<body>` with nothing
announced; `outline-none` on every form control replaces the global 2px focus ring with a
1px border colour change on `:focus` rather than `:focus-visible`.

### 9. The city cluster is orphaned and 60% duplicate — HIGH

Neither `Nav.tsx` nor `Footer.tsx` links to `/ai-receptionist`. The only editorial inbound
link on the site is one entry in `data/blog.ts:159`. That is a 9-URL cluster, 14% of the
site, at crawl depth 3+. `SEO.md` Lever 1 predicts this outcome.

Measured on the built HTML with chrome stripped, 4-gram overlap:

| Set | Pages | Mean overlap | Max pair |
|---|---|---|---|
| `/ai-receptionist/*` | 8 | **60%** | 64% |
| `/voice-ai/*` | 7 | **49%** | 55% |
| `/compare/*` | 9 | 30% | 39% |
| `/solutions/*` | 9 | 27% | 37% |
| `/use-cases/*` | 3 | 24% | 25% |
| `/blog/*` | 8 | **1%** | 1% |

Four of the five FAQs on a city page are byte-identical prose across all eight, so 61% of
the visible words on a city page are shared with its siblings. This is `SEO.md` Lever 2's
failure mode word for word. The compare and solution sets show the differentiation work was
understood; it was not applied to the two programmatic clusters that need it most.

**Fix:** link `/ai-receptionist` and the eight cities from the footer, and move 3 of the 5
FAQs into `data/cities.ts` as per-city entries. Same for `/voice-ai/*`.

### 10. No linter, no CI, no CSP — MEDIUM

`npm run lint` cannot run (no ESLint config). There is no `.github/` directory: nothing
typechecks, lints or builds on a pull request, despite both scripts existing in
`package.json`. `next.config.ts:21-32` sets three headers and is missing
`Content-Security-Policy`, `Strict-Transport-Security` and `Permissions-Policy` — which
matters because `app/layout.tsx:170` injects a remote voice widget on all 65 pages,
including the three carrying the lead forms, and it will request microphone access with no
`Permissions-Policy: microphone=(self "https://app.decibyl.ai")` boundary.

Add a PR workflow running `npm ci && npm run typecheck && npm run build`, an ESLint config,
and Dependabot.

### Smaller, each a real defect
- `/experience` is missing from `data/pageDates.ts`, so the newest page claims the oldest
  `lastmod`. `npm run dates` is not picking the route up.
- 48 of 65 `lastmod` values are identical, because the four programmatic sets carry one
  per-file date each.
- The eight city pages restate the company inline as an anonymous `Organization` node
  (`app/ai-receptionist/[city]/page.tsx:208`) instead of `orgRef`, undoing on 8 URLs the
  entity consolidation `lib/seo.tsx:71-86` exists to do.
- `LEGAL_UPDATED` is one constant across all four legal pages, while `pageDates.ts` records
  the terms as changed 16 days later, after the "credit, not minutes" rewrite.
- `app/legal/refund/page.tsx:156` sells "unused minutes", which `data/pricing.ts`'s CONTRACT
  block says does not exist in the product. This is the one document Razorpay requires.
- The privacy policy discloses Vercel Analytics; it is not installed.
- `/api/og` is robots-allowed, unsigned and unrated, so anyone can mint a first-party-looking
  1200×630 Decibyl card from arbitrary text. No SSRF and no XSS (Satori escapes into a PNG,
  no remote fetch, both inputs length-clamped) — the issue is brand abuse and unbounded
  render cost. HMAC-sign the params in `ogImagePath()`.
- `lib/seo.tsx:269` injects JSON-LD without escaping `<`. All inputs are repo-controlled
  today; a `</script>` in any FAQ answer would break out. `.replace(/</g,'\\u003c')`.
- `lib/rate-limit.ts:41` takes the left-most `x-forwarded-for` hop. Vercel overwrites it so
  this is not live, but it is what makes `ip_hash` forgeable. Do not copy the pattern.
- The widget token at `app/layout.tsx:170` is a hardcoded literal, so it cannot be rotated
  without a deploy. Also `lib/site.ts:138` declares `app: 'https://inapp.decibyl.ai'` while
  the widget loads from `app.decibyl.ai`.
- README and `OPEN-ITEMS.md` both place the scroll story on the home page; it is on
  `/experience`. `OPEN-ITEMS.md` is stale on four prices it exists to gate (Growth ₹9,999 vs
  shipped ₹7,999, Scale ₹34,999 vs ₹19,999, BYOK trial $10 vs $5) and its palette-deviation
  table is wrong on all four rows, which is why the contrast regression in §8 went unnoticed.
  The README's design-system section still describes the vermilion/saffron palette the violet
  redesign replaced.
- `components/story/ScrollStory.tsx:12` declares a `phone` prop it never uses;
  `NEXT_PUBLIC_BUILD_SHA` is defined in `next.config.ts:14` and read by nothing.

## What the site does well

- **Static generation is enforced, not aspirational.** All six dynamic segments set
  `dynamicParams = false` alongside `generateStaticParams`; only the two API routes are `ƒ`.
- **The SEO plumbing is close to flawless.** 65 sitemap URLs matching 65 real pages exactly,
  one canonical and one `<h1>` per page, no duplicate titles or descriptions, complete
  OG/Twitter tags, valid JSON-LD with stable `@id`s consolidating the entity graph, preview
  deploys correctly blocked from the index, and an `llms.txt` that instructs answer engines
  not to over-claim certifications.
- **The honest-content discipline is real and rare.** Empty `logos` and `caseStudies` with
  enforcement comments, a security page naming ISO 27001, SOC 2 and HIPAA as **not** held,
  competitor comparisons that volunteer where the competitor is stronger, sample transcripts
  labelled as illustrations. The three violations above stand out because everything around
  them holds the line.
- **JS is genuinely lean.** 103 kB shared First Load, 115 kB on `/`, 131 kB on the form
  pages. Only 12 files carry `'use client'`, the heavy layout components are all server
  components, fonts are self-hosted via `next/font` with `display: 'swap'`, and there is no
  animation library — exactly what the README requires.
- **The repo audits itself.** `scripts/seo-audit.mjs` reads the *built* HTML rather than the
  source, strips the RSC payload so the similarity maths means something, and is
  zero-dependency and offline. `data/pricing.ts` carries a CONTRACT block naming which
  product constant each figure must track. Both catch the next regression rather than
  documenting the last one.

## Limits

`tsc`, `next build` and `scripts/seo-audit.mjs` were run. No live site was fetched, no
Lighthouse or field data was collected, no dependency advisory scan was run, and no browser
or real-device testing was performed. Asset weights are measured on disk; contrast ratios
and 4-gram overlaps are computed from the build output. Every finding names its file and
line — disagree with any of them by reading the code it points at.
