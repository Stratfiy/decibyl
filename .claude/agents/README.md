# Project agents

66 subagents from [msitarzewski/agency-agents](https://github.com/msitarzewski/agency-agents) (MIT, licence in `LICENSE-agency-agents`), limited to the divisions this repo's work needs: marketing, paid media, sales, product, finance, support, and the customer-facing specialised personas (customer service, hospitality, legal intake, loan officer, retail returns, healthcare service, real estate). Engineering, game, GIS, China-platform and academic agents were left out on purpose; pull them from the source repo if needed.

Names were normalised to kebab-case to match the filename. Invoke with the Agent tool, e.g. `subagent_type: marketing-seo-specialist`. The customer-facing personas double as first drafts for Decibyl shelf-role prompts.
