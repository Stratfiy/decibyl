BUILD THE BOT

More than one way to get it done.

01

Ready-made bot packs

Start from front desk, order confirmation, lead qualification, admissions, knowledge, and scheduled reminder templates.

02

Prompt-first and visual editing

Write the instructions or use a connected workflow canvas with branches, waits, webhooks, and handoffs.

03

Per-agent voice and models

Choose speech recognition, language model, voice, speaking style, and fallback configuration for each agent.

04

Tools, knowledge, and variables

Attach external tools, reference documents, dynamic context, extraction fields, and calculation or rate-table tools.

05

Version history and duplication

Keep versions of a workflow and reuse an existing agent as the starting point for another.

06

Build through MCP or SDKs

Use the MCP workflow tools, HTTP APIs, or Python and TypeScript SDKs for developer-led setup.

RUN THE WORK

More than one way to get it done.

01

Inbound and outbound calls

Route incoming calls to an agent or trigger outbound conversations from a campaign or your backend.

02

Browser voice and text

Test with audio in the browser, iterate in text, and make selected agents accessible through share links or a web widget.

03

Scheduled routines

Run supported jobs on a schedule. A routine does not need a phone number when its task is non-calling.

04

Multi-agent squads

Hand off between specialist agents inside a configured workflow with explicit transition logic.

05

Campaign controls

Upload contacts, configure campaigns, pause or resume work, and use do-not-call and consent checks.

06

Human escalation and keypad input

Add transfer rules and DTMF collection. Verification services and OTP validation require your connected system.

LEARN AND IMPROVE

More than one way to get it done.

01

Recordings, transcripts, and captions

Review conversations, live test captions, and run details. Access to stored media uses signed links.

02

Post-call quality review

Configure quality checks, summaries, structured extraction, dispositions, and evaluation criteria.

03

Review inbox and outcomes

Review flagged runs, record outcomes, and follow the result beyond a completed call.

04

Usage and cost visibility

Inspect spend and component usage so you can understand what each configured workflow consumes.

05

Shared and bot-specific memory

Retain selected durable facts, trace them to their origin, and keep bot-specific instructions separate.

06

Company knowledge graph

Use the optional graph infrastructure to ingest relationships from supported activity; availability depends on deployment.
